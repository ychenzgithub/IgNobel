# 搞笑诺贝尔奖全纪实编年史 (1991–2026) | The Ig Nobel Prize Chronicle (Bilingual)

> **“先让人捧腹大笑，再让人掩卷深思。”**  
> *“First make people laugh, and then make them think.”*

本项目严格依据搞笑诺贝尔奖官方网站（[https://improbable.com/ig/winners/](https://improbable.com/ig/winners/)）历届获奖名单与原始学术文献编纂，以**中英双语编年史**的形式完整呈现 **1991年至2026年共36届、357项真实获奖研究**。

Faithfully compiled from the official [Improbable Research](https://improbable.com/ig/winners/) archives and primary peer-reviewed literature, this interactive bilingual chronicle documents all **36 ceremonies and 357 real Ig Nobel Prizes awarded from 1991 to 2026**.

---

## ✨ 内容与特色 / Key Features

1. **全纪实零幻觉考据（1991–2026） / 100% Fact-Checked Archives**
   - 完整覆盖从1991年首届至2026年第36届的全部官方获奖名单、获奖学者及发表期刊背景，史实准确零幻觉。
2. **中英双语自由切换 / Seamless Bilingual Switching (`中文` | `English` | `中英对照`)**
   - 支持**纯中文**、**纯英文**与**中英段落对照**三种语言模式一键切换。
   - 每一年均配有约800字中文幽默纪实长文与约500词地道诙谐的英文纪实长文，串联解读当年所有获奖课题。
3. **72幅中英双语原创科学漫画配图 / 36 Bilingual Editorial Cartoons (ZH & EN SVGs)**
   - 每一年均挑选一项最具代表性的获奖研究绘制专属矢量科学漫画配图（同时提供中文版 `images/1991.svg`–`2026.svg` 与英文版 `images/1991_en.svg`–`2026_en.svg`，并在 `index.html` 内随语言自动切换）。
4. **沉浸式阅读交互体验 / Rich Interactive Reading Experience**
   - 年代筛选（`1990s` / `2000s` / `2010s` / `2020s`）、跨语言中英文实时检索、随机年份穿越（`🎲 随机一年 / Random`）
   - 三种阅读视图切换：**📖 编年史全文 (Full Chronicle)**、**🎨 配图画廊 (Gallery)**、**🗂️ 获奖名录 (Directory)**
   - 日间/夜间模式切换、三档字号调节、配图灯箱放大预览与 SVG 矢量图下载
   - 页脚集成不蒜子（Busuanzi）中英双语访问统计组件

## 📂 文件结构 / Repository Structure

- `index.html`：完整单文件自包含交互式双语编年史网页（内嵌全部36年中英文章、357项双语奖项卡片与72幅中英文矢量配图）
- `images/1991.svg` ~ `images/2026.svg`：36幅历年代表性获奖研究中文版 SVG 配图
